Project

tagshelf

Go, for Windows and Linux, since Oct 2026

Sorts audio files into a music library by their tags. It sets identical copies aside instead of deleting them, and records every move so a run can be undone.

  • A CLI for runs, and a terminal UI for the files that need a person: fixing tags, MusicBrainz lookups, choosing which duplicate to keep.
  • Static builds for Windows (amd64) and Linux (amd64 and arm64) that need no C library, with CI on GitHub and checksummed releases.
  • Does a dry run first, never deletes an audio file, and migrates its own database on upgrade, keeping a backup of the old one.
